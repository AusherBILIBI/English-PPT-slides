# Style Routing

## Default Choice

Use one skill and route by prompt wording:

- Choose `warm-study-space` when the user asks for warm classroom courseware, orange classroom style, sentence imitation, reading-continuation writing, unit composition summaries, expression training, or answer reveal.
- Choose `clean-handout` only when the user asks for topic-writing guidance style, clean handout style, white minimalist pages, image-left title-right cover pages, or the alternate style from the topic-composition gold decks.
- Choose `plain-classroom` when the user requests public sharing, no brand, no logo, exam-like projection, or when the source/template does not justify a richer style.

Ask a concise clarification only if the user names two conflicting styles and the deliverable would visibly change.

## `warm-study-space`

Use for most courseware:

- warm orange background or border treatment;
- large black section titles;
- cream or white rounded cards for content blocks;
- red English answers when answers should reveal;
- black Chinese prompts;
- compact but readable density;
- lower-right page numbers when used by the reference;
- optional neutral course label in the top-right, or leave it blank for public decks.

Do not include private company names, logos, or historical brand text in a public deliverable. When a gold PPT contains private marks, use it as a layout reference and remove or replace the mark in the new deck.

## `clean-handout`

Use for topic-writing guidance and formal handout-style decks:

- white background;
- large high-quality topic image on cover or unit divider pages;
- large black unit/title typography;
- restrained blue section labels when useful;
- thin divider lines and generous margins;
- two-column writing-task and review-guidance layouts;
- small page numbers in the lower-right.

This style is different from warm orange courseware. Do not apply orange cards, answer badges, or dense reveal layouts unless the user explicitly combines the styles.

## `plain-classroom`

Use for public, neutral, or exam-like outputs:

- white background;
- large black titles;
- clean editable text blocks;
- minimal page furniture;
- no logo, no private label, no decorative chrome.

## Prompt Examples

- "Use warm-study-space style to make a reading-continuation sentence imitation PPT."
- "Use clean-handout style for topic-writing guidance."
- "Make a public version with no private brand marks."
- "Use the answer-reveal gold examples and keep answers Fade / On Click."
