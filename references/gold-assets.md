# Gold Assets

Bundled gold PPTX files are reference assets for layout stability and lower-token future builds. They may still contain historical private labels, logos, or source-specific wording. Review and scrub them before external publication.

Fast visual previews live in `assets/style-previews/`. Use them to choose a style route quickly, then open the relevant gold PPTX before doing final layout-sensitive work.

## Usage Rule

Open the matching gold PPT before building a new deck. Copy structure, density, spacing, color role, and animation behavior. Replace the actual teaching content with the current source unless the user explicitly says to reuse old content.
